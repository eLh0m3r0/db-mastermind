Privacy policy

This program will not transfer any information to other networked systems unless specifically requested by the user or the person installing or operating it.

DB Mastermind has no telemetry, no analytics, no crash reports and no account. Here is everything it connects to, and when.

Update checks

The only thing the app does on its own: every few hours it asks GitHub for the latest release and, if there is a newer one, downloads it. GitHub sees your IP address and the app version, under the GitHub Privacy Statement.

  • Turn it off in Settings → General → Updates. Help → Check for Updates still works when you ask.
  • IT can turn it off for everyone with the disableUpdateCheck policy.

Databases

The app connects only to the databases you set up, directly or through the SSH tunnel you configure.

AI assistant

AI is off until you set up a provider. Then your questions, and the schema and data the assistant reads to answer them, go to the provider you chose, under its privacy policy:

  • Anthropic (also when you use your Claude Code subscription)
  • OpenAI (also when you use Codex)
  • OpenRouter
  • Google Gemini
  • Azure OpenAI
  • Ollama runs on your own computer: nothing leaves it.

Each connection can have AI turned off or limited to the schema without data, and IT can turn AI off for all connections.

MCP server

Off until you add DB Mastermind to an agent or turn on the local HTTP endpoint. The endpoint listens only on your own computer (127.0.0.1) and needs a token. Agents see only the connections where you allow AI.

Passwords and keys

Saved passwords and API keys are encrypted with your system keychain (macOS Keychain, Windows DPAPI, the Linux secret service; on a Linux system without one the app says so in Settings) and are sent only to the database or AI provider they belong to. Exported connections never include them.

This website

The site is hosted on GitHub Pages. The download button asks GitHub which file is the latest; there are no cookies or trackers.
