For DeZign for Databases users

Open your DeZign for Databases projects in DB Mastermind, edit them and save them back into the same project, without DeZign installed. A team can switch person by person: whoever still uses DeZign opens the same files.

DB Mastermind is a free, open-source database client and data modeler (MIT license). Everyone on a team can use it, at work too, without a licence for it.

What opens

  • Single-file projects (.dez) and folder projects (.dezproj), made with DeZign 4 to 14.
  • The project's diagrams, with their tables, positions, notes and colors.
  • Open a project from the home page, from File → Open Model, or drop it on the window.

What is kept

Domains, attribute packages, subtypes, labels, custom properties, to-do items, triggers, procedures, sequences, archived versions and reports stay in the project, and you can switch its target database.

Saving back

  • Before anything is written, the app lists the changes it will save, and a backup of the project is kept.
  • The saved project is read back and compared with what you edited; if they differ, nothing is written.
  • Checked in DeZign 14.9.3, which opens the saved files and saves them again with nothing lost.
  • A model you start in DB Mastermind can be saved as a new DeZign project too (Save as…).

SQL from a DeZign project

Scripts made from a DeZign project follow the project's own settings: its names, primary key names and domains, as DeZign generates them. Compare the model with a live database to get the migration, with the existing data checked first and a rollback script.

Beyond the model

The same app is a database client: browse and filter data, write SQL with autocomplete, see ER diagrams of a live database, compare schemas and data, and ask an AI that knows your database. See Modeling and all features.

If something doesn't come through

Please open an issue and describe what was lost. Don't attach a project with confidential content: a small project that shows the problem is enough.
