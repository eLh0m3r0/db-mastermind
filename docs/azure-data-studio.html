Coming from Azure Data Studio

Microsoft retired Azure Data Studio on February 28, 2026. It no longer gets updates or security fixes.

Microsoft recommends Visual Studio Code with the MSSQL extension instead, and SQL Server Management Studio for administration (Microsoft Learn: What's happening with Azure Data Studio, checked on November 21, 2026). If you would rather have a standalone database app, this page says what you will find in DB Mastermind, and what you won't.

DB Mastermind is a free, open-source database client and data modeler for Windows, macOS and Linux (MIT license, no paid tier). Besides SQL Server and Azure SQL it works with PostgreSQL, Oracle, MySQL, MariaDB, SQLite, DuckDB, ClickHouse, CockroachDB, BigQuery and Trino.

Your connections

  • Import connections reads Azure Data Studio's settings and brings over its SQL Server, PostgreSQL and MySQL connections. Passwords are not imported: the app asks for one when you connect, and saves it encrypted with your system keychain if you tick Save password.
  • SQL Server sign-in with a SQL login, with Windows authentication (on Windows, your domain account, no password), or with Microsoft Entra ID (your Azure account through az login, VS Code, environment variables or a managed identity, or a service principal). Entra ID sign-in is built on the SQL Server driver's own support and has not yet been tested here against a real Azure tenant: if it fails for you, please open an issue.
  • SSH tunnels and jump hosts, TLS, read-only connections and a production guard.

Queries

  • An SQL editor with autocomplete from your schema (it writes whole JOINs from foreign keys), warnings while you type, snippets, history and saved queries.
  • Several result sets from one batch, with PRINT and RAISERROR messages next to them.
  • Execution plans as a tree, and a comparison with the previous plan.
  • Export every row of a result to CSV, Excel, JSON or SQL.
  • Transactions you can see: you commit yourself, per connection, and every open transaction is shown.

Server activity

  • Sessions and running queries, lock waits (who blocks whom), cancel a query or end a session.
  • The most expensive queries from the server's query statistics.
  • Table and index sizes, with indexes that are never used or repeat another one.
  • Users and roles with their memberships and permissions (read-only), and backup and restore through BACKUP and RESTORE.

Notebooks

Azure Data Studio's .ipynb notebooks don't open here. The closest thing is a knowledge base: a folder of Markdown notes per database, where SQL blocks run in place and show their results (read-only). The notes are plain files you can keep in Git, and the AI assistant and agents read them too.

More than a query tool

  • Schema compare between two databases with the migration script, and data compare with a sync script.
  • ER diagrams of a live database, the join path between any two tables, and table design on the diagram with a reviewed migration.
  • An optional AI assistant with the AI you choose (your own API key, a Claude Code or Codex subscription, or a local model), and an MCP server for agents. Off until you set it up.

Not in DB Mastermind

  • SQL Server Agent jobs, a profiler or Extended Events sessions.
  • SQL database projects, DACPAC and BACPAC.
  • Extensions: the app has no extension marketplace.
