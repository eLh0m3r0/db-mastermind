How releases are built and signed

  • Every release is built by GitHub Actions from the tagged source in the project's repository; nothing is built or signed on a personal computer.
  • Only files built from this project's own source are signed. Contributions from outside the team are reviewed before they are merged.
  • Each signing request is approved by hand by an approver.
  • All team members use multi-factor authentication for GitHub and SignPath.

Privacy

This program will not transfer any information to other networked systems unless specifically requested by the user or the person installing or operating it. Details: privacy policy.

Installing and uninstalling

  • Portable zip (Windows): changes nothing on your system. Delete the folder to remove it; your data is in the data folder next to the app.
  • Windows installer and MSI: add a Start menu entry; remove the app in Settings → Apps → Installed apps.
  • macOS: move the app from Applications to the Trash.
  • Scoop / Homebrew: scoop uninstall db-mastermind or brew uninstall --cask db-mastermind.
  • Linux: delete the AppImage, or remove the .deb package with your package manager.

Installed versions keep settings and connections in your user data folder (Settings → About → Data folder) until you delete it.
